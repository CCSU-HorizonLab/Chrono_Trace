## 微信聊天记录分析应用：开发规划指令 (Prompt)

### 1. 任务背景

开发一个纯本地运行的桌面端工具（Python 为主），处理已存入 SQLite 数据库的微信聊天记录。目标是通过量化指标，生成情感分析报告并提供策略建议。

### 2. 技术栈约束

* **核心语言：** Python 3.9+
* **本地 NLP：** `jieba` (分词), `SnowNLP` (基础情感), `scikit-learn` (余弦相似度计算)
* **数据处理：** `Pandas`, `Numpy`, `SQLite3`
* **不使用云端 API：** 所有逻辑必须在本地 CPU 运行。

---

### 3. 数据处理流水线 (Pipeline) 规划

#### 第一阶段：数据预处理 (Data Pre-processing)

* **会话切割逻辑：** 编写函数，遍历时间戳。若两条消息间隔 > 3600秒 (1小时)，标记为一个新的 `Session_ID`。
* **清洗算子：**
  * 正则过滤：删除 `<msg>...</msg>` (XML/系统消息), `[表情]`, `[图片]`, `[视频]`。
  * 统计算子：记录每个消息条目的字符长度、时间戳、发送者身份（Me/Target）。

#### 第二阶段：特征提取 (Feature Engineering)

AI 需要编写以下指标的计算函数：

1. **Response_Time (响应时长)：** 计算 Target 收到 Me 消息到回复之间的时间差。需剔除睡眠时间（如 00:00 - 07:00）。
2. **Initiative_Rate (主动率)：** 在所有 `Session_ID` 中，由 Target 发起首条消息的次数占比。
3. **LSM (语言风格匹配)：** 提取双方常用的“虚词”（如：的、了、呢、吧、吗、就、也）。计算两组词频向量的 **余弦相似度** 。
4. **Word_Ratio (字数投入比)：** `Target总字数 / Me总字数`。

#### 第三阶段：维度量化 (Dimension Scoring)

AI 需实现一个评分模型，将特征转化为 0-100 分：

* **积极度 (Active Score)：** 由回复频率、回复速度、字数加权计算。
* **情感值 (Sentiment Score)：** 对 Target 的每条文本运行 `SnowNLP(text).sentiments`，求窗口平均值（重点分析最近 50 条）。
* **共鸣感 (Resonance Score)：** 由 LSM 相似度与表情包重复度决定。

#### 第四阶段：策略引擎 (Strategy Engine)

建立一个简单的“决策树”：

* **Case A (好感度 > 80且积极)：** 建议“更亲密”，话术库侧重于“自我暴露”和“邀约”。
* **Case B (好感度 < 50且下降趋势)：** 建议“疏远”，策略侧重于“推拉”和“减少可得性”。
