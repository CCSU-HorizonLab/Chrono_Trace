# 文档归档

本目录保存历史材料，供追溯实现过程和旧评测结果使用。归档内容不作为当前产品行为、验收标准或开发入口；新工作请从 [`docs/README.md`](../README.md) 和当前 RAG v4 文档开始。

## 目录

- [`plans/`](plans/)：RAG v1、早期增量方案和记忆意图方案，已被 v4 路线取代。
- [`execution/`](execution/)：已经完成的端到端任务和 RAG v4 P0–P3 施工记录。
- [`evaluations/`](evaluations/)：旧版样例、模板、smoke 回放和阶段性评测 JSON。
- [`reports/`](reports/)：被最新后评估报告取代的代码审查报告。
- [`frontend/`](frontend/)：早期前端重设计和主题更新说明。
