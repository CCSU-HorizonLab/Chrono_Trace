# Chrono Trace 关系章节：画像演变与全量语料（persona-chapters）

## 文档状态

- **阶段**：已完工（C1~C4 全部落地，2026-10-24；C4 真机目检待补）
- **建立日期**：2026-10-23
- **前置**：v2.2.0；画像时间窗口径见 [profile-window.md](../analysis/profile-window.md)、大五口径见 [time-depth.md](../analysis/time-depth.md)
- **背景**：现有画像系统两大方法性缺陷——①均分切段×独立快照读不出「演变」；②rolling 窗采样对长会话只覆盖尾部（90 天窗罩 8%），全量语料的语义层整层缺席。经联网调研（2026-10-23）确定换时间原语方案。

## 调研依据（结论与出处）

| 发现 | 出处 | 对设计的指令 |
|---|---|---|
| 人格是**状态的密度分布**，逐段点分把分布压成一个数，段间差异多为分布内正常波动 | Fleeson Whole Trait Theory（2015，引 1400+） | 大五演变呈现改为**分布带**（逐周代理分→分位带），不做逐段雷达点分叙事 |
| 整库语料的消化法是**摘要金字塔**（分块摘要→逐级归并），LLM 不必一次看全文 | RAPTOR / map-reduce 摘要模式 | 全量语料经**月摘要→章节摘要→全局弧线**参与画像 |
| 分段的正确切法是**行为变点检测**，不是均分 | Aminikhanghahi & Cook 2016 综述（引 2100+） | 章节按消息量/占比/情感/时延四信号的最优分段切 |
| 章节需要**阶段词汇表**（走近/走远） | Knapp 关系发展阶段模型；Duran 2017 验证数字通信适用 | 章节阶段标签用 LLM 观察叙事措辞，**不做关系诊断** |
| 「什么变了」可专门生成（带归因的差异摘要） | STRUM-LLM / 对比摘要研究 | 相邻章节间生成**过渡卡** |

## 架构（数据流）

```text
原始消息（全量）+ 情感缓存 + sessions + response_times + 里程碑
    │
    ├─ ① 章节检测（纯统计零 LLM）：周粒度 消息量/TA占比/正向率/回复时延
    │     → z 归一 → DP 最优分段（惩罚项选段数）→ 边界吸附 ±7 天内里程碑
    ├─ ② 摘要金字塔（LLM，增量缓存，C2）：月摘要 → 章节摘要 → 全局弧线
    ├─ ③ 过渡卡（对比式生成，C3）：相邻章节「什么变了/触发/什么没变」
    └─ ④ 呈现：章节时间线 + 大五分布带 + （C3）过渡卡与阶段标签
```

## 口径与版本常量

| 常量 | 位置 | 当前值 | 何时 +1 |
|---|---|---|---|
| `CHAPTERS_VERSION` | relationship_chapters.py | 1 | 章节检测口径（特征/惩罚/吸附）变化——前端按版本丢弃旧缓存 |
| `WEEKLY_MIN_SIDE_TEXTS` | 同上 | 10 | 周级大五留白阈值调整 |
| `MAX_CHAPTERS` / `MIN_CHAPTER_WEEKS` | 同上 | 8 / 2 | 分段约束调整 |
| `MONTHLY_SUMMARY_VERSION` | chapter_summaries.py | 1 | 月摘要 prompt 字段/采样预算变化——旧月报失明重算（月表带版本列） |
| `CHAPTER_SUMMARY_VERSION` | chapter_summaries.py | 2 | 章节叙事层（归并/过渡卡/弧线）prompt 措辞或结构变化——旧叙事失明重算；v2 = phase 不确定性措辞 + 过渡卡 + 弧线 |
| `PROFILE_SNAPSHOT_SCHEMA` | contact/self_profiler.py | 5 | v4 = 新增【关系章节摘要】注入块；v5 = origin 来源列（演变段/滚动/指定窗区分，口径详见 profile-window.md） |

- 周桶锚点：本地时区周一 00:00；空周保留（冷却期本身是信号）。
- 周级大五缺席指标（unanswered/revoke/positive_response 等）不采，按 big5_proxies 点数制重归一——分布带只做相对演变叙事，不做绝对测评解读。
- 章节检测为纯函数确定性输出；同库重跑结果一致（可测试锁死）。
- C2 起的 LLM 链路全部在 PrivacyRedactor 之后（红线沿用大五增强层纪律）。

## 回滚

- C1 纯统计层独立面板，出问题摘除面板即可，不触既有画像/大五链路。
- C2 rolling 画像改采样层前保留旧采样路径开关（按会话回退），快照 schema_version 隔离旧口径。
