# py_wx_key 接入 Chrono Trace 任务计划

## 目标

将 `py_wx_key` 接入 Chrono Trace，自动获取微信数据库密钥，并复用现有的数据库密钥验证、解密和导入流程。

图片密钥相关功能暂不接入；现有手动输入数据库密钥流程始终保留为回退方案。

## 独立验证运行方式

先退出当前微信并重新启动到登录界面，不要先完成登录。随后用 PowerShell 7 运行：

```powershell
pwsh -NoProfile -Command "& '.venv/Scripts/python.exe' 'tools/verify_wx_key_capture.py' --timeout 120"
```

如果检测到多个微信进程，使用输出中的主进程 PID 重试：

```powershell
pwsh -NoProfile -Command "& '.venv/Scripts/python.exe' 'tools/verify_wx_key_capture.py' --pid <微信PID> --timeout 120"
```

看到“Hook 初始化成功”后，再在微信中完成登录或执行会读取数据库的操作。脚本只显示脱敏后的密钥首尾，不会调用图片密钥接口，也不会写入 Chrono Trace 数据库。

## 关键风险

1. Hook 可能需要管理员权限。
2. `wx_key` 当前构建产物绑定 Python 3.12 x64。
3. 捕获数据库密钥可能需要微信重新登录或触发登录动作。
4. 多微信进程或多账号时，需要额外确认进程与账号目录的对应关系。
5. 打包时需要确认 `.pyd` 和 MSVC 运行库被正确带入产品。
