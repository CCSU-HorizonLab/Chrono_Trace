# Chrono Trace Beta 1.1 发布说明

**版本**：v1.1.0-beta.1 ｜ **日期**：2026-09-25 ｜ **上一版本**：v1.0.0-beta.1（2026-09-24）

本版是记忆系统（RAG v4 改造）的集中落地版本：关系理解、事实维护、抽取质量、并发稳定性四个方向，共 30 项提交。

## 记忆与关系理解（核心更新）

### 对方偏好与雷点成为独立记忆策略

- 偏好/雷点事实自动聚合为主题策略槽：同一偏好的多次表达合并为一条，重复确认提升置信度。生成建议时以独立速查清单注入，顺着偏好、避开雷点；当下对话有明确不同表态时以当下为准。
- 关系策略（关系阶段/亲密度/相处边界/沟通建议）与偏好策略分槽注入，互不挤占预算；LLM 抽取的事实全部进入关系证据范围（此前与关系策略完全脱节）。
- 相处边界摘要区分"对方的边界"与"我的边界"。

### 事实演变链生效（"以前不喜欢 → 现在改观了"）

- 修复事实融合协议：新旧事实的修正/取代/合并决策此前从未真正执行，现在形成可追溯的演变链，不再产生自相矛盾的重复记忆。
- 修复演变链被后续索引重建复活的问题。

### 用户纠错即时生效

- 记忆标记「不准确/忘记」后，引用该记忆的关系策略与偏好策略即时刷新，不再出现"已标记错误的记忆仍被建议引用"；「还原」同样触发刷新。
- 建议的采纳/改写行为积累为反馈信号；改写差异自动提取偏好候选（影子模式，经校准后启用）。

## 抽取质量强化

- 代指残句拦截："有钱了搞一台""我们后天搬""没那么想要"这类脱离上下文无法理解的碎片不再入库。
- 交易细节拦截："早餐钱""转你20"等一次性金钱往来不再记为事实。
- 游戏内购买排除：游戏商店、卡牌、皮肤的购买操作不再误记为消费；仅当反映稳定长期偏好时作为偏好记录。
- 原型碎片清理：旧匹配路径产生的 12 字以下短碎片（约占旧记忆池 80%）全部拦截并清理。
- 抽取自包含性强化：每条事实经"删掉对话后还能被理解吗"自检；断点续抽按段级进度推进，抽取规则改进后自动重抽历史。

## 稳定性修复

- 数据库并发根治：消除"任何相关操作触发 database is locked 且锁死"的问题。异常路径不再遗留持锁事务（4 线程 40 万次并发操作含故障注入验证，零锁错误）。
- 索引重建并发：连续触发多个联系人的重建时自动排队串行完成，不再互相锁死。
- 隐私红线：远程模型脱敏器不可用时阻断该段发送，绝不降级发送原文。
- 事实融合调用防截断：候选上限、输出上限与失败诊断日志。

## 可观测性与设置

- 每次建议生成全链路可追溯：触发类型、召回、门控、注入、使用的策略版本均落库。
- 修复 Beta 1.0 中「AI 抽取记忆事实」「关系策略」开关保存后丢失的问题。
- 记忆弹窗：支持按类型/排序筛选，可查看已禁用（被标记不准确/忘记）的事实；RAG 设置卡片改版，每个开关附说明提示。

## 其他

- 修复微信账号目录识别漏扫非 wxid 前缀账号的问题。
- 修复自动重启后密钥捕获误判版本失败的问题。
- 打包链路修复（scipy 子模块收集、WebView2 引导器依赖）。

## 升级说明

- 直接安装覆盖升级，数据（聊天记录/记忆/设置）保留。
- 首次启动后建议：确认设置中的「AI 抽取记忆事实」与「关系策略影子」开关已开启，并对常用联系人执行一次索引重建——新质量门会自动清理历史碎片，LLM 重新抽取更完整的记忆。
- 事实记忆全部本地处理；使用远程大模型时内容默认脱敏。

## 已知限制

- 建议质量的量化验收体系（人工回归集）建设中，当前以检索自洽性验证与人工事实抽查为准。
- 偏好候选自动学习暂为影子模式（记录但不生效），待人工校准后启用。
