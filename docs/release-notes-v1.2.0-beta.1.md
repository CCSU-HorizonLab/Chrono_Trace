# Chrono Trace Beta 1.2 发布说明

**版本**：v1.2.0-beta.1 ｜ **日期**：2026-09-27 ｜ **上一版本**：v1.1.0-beta.1（2026-09-25）

本版共 107 项提交，四条主线：记忆系统治理（提取质量与回补效率）、导入与分析性能（增量链路）、并发稳定性、界面体验。

## 记忆系统

### 记忆提取质量
- 消费类话题（购买、餐饮）不再由关键词匹配直接入库，改由大模型语义判断是否为值得长期记忆的偏好或计划——购物闲聊、游戏内商店购买不再产生垃圾记忆。
- 代词残留拦截：脱离上下文无法理解的碎片不再入库。
- 跨天代词还原：记忆提取时自动检索语义相关的更早讨论作为上下文——数天前提过的物品，在后续对话中可被正确还原。
- 记忆演变链：同一事实的立场变化（"以前不喜欢、现在改观了"）形成可追溯的取代链，不再并存自相矛盾的记忆。

### 记忆提取效率与覆盖
- 批量回补：新增"回补记忆抽取"入口，为历史消息尚未提炼记忆的联系人一次性排队后台抽取（消耗 Token，弹窗明示）。
- 回补提速：寒暄段预筛（不送模型）+ 3 路并发调用，较初版提速约 4-6 倍；未完成自动续轮，无需反复手动触发。
- 修复先配记忆后配模型的顺序问题：此前在未配置大模型时构建过的联系人，配置后再重建会被增量水位短路，历史记忆永远无法提取——现在自动识别并回补。

### 记忆管理
- 修复"清空"不彻底：此前仅清除文档层，事实、关系画像、偏好全部残留；现在全部提炼数据彻底清除并停用该联系人记忆（可重新启用），且不会被自动重建复活。
- 标记"不准确/忘记"后，引用该记忆的关系画像与偏好策略即时刷新。
- 记忆弹窗支持查看已禁用（被标记不准确/忘记）的事实。

## 导入与分析性能

- 日常增量导入免全量扫描：导入耗时约 70 秒降至秒级。
- 解密快照跨进程复用：重启后导入免全量重解密（实测 38 秒降至 0.3 秒）；监听检测延迟 3 秒降至亚秒。
- 分析结果新鲜度提示：导入新消息后前端提示分析待更新；分析完成后自动为该联系人构建记忆索引。
- 嵌入向量持久缓存：重复分析只计算新增文本。
- CPU 线程调优：消除超线程争抢导致的高占用低产出。

## 稳定性

- 数据库并发根治：消除"任何相关操作触发 database is locked 且锁死"（连接层自动提交，异常路径不再遗留持锁事务）。
- 索引重建并发：连续触发多个联系人重建自动排队串行完成，不再互相锁死全部失败。
- 隐私红线：远程模型脱敏器不可用时阻断该段发送，绝不降级发送原文。
- 修复监听运行中退出应用触发崩溃、画像生成按钮无反应、取消分析后界面卡"分析中"等问题。

## 界面体验

- 联系人记忆与建议依据面板统一术语为"记忆"；RAG 设置卡片改版，开关附说明。
- 关闭确认弹窗重设计；微信 4.0 升级引导弹窗。
- 联系人选择器懒加载（千级联系人不再卡顿）；悬浮窗多项滚动与选中修复。
- 实时助手/联系人洞察页面重组：画像可直接生成，跨页联系人选中状态共享。

## Linux 支持（新增平台）

- 全链路移植（六个阶段）：注册表/窗口 API 解耦、实时监听（inotify db_watch）、悬浮窗、UI 自动化、关闭拦截、启动监听；提供 tar.gz 打包链路与依赖清单。
- 修复微信 contact/session 目录含多个库时的识别问题；Linux 下启动监听的版本提示适配。

## 实时监听稳定性（补充）

- 修复监听收到 0 条消息的根因（刷新时机）；db_watch 双缺陷修复（WAL 场景与常驻监听）。
- 解密快照同文件边读边写加页校验，避免读到半写状态。
- 监听子进程随应用退出自动终止（PDEATHSIG）；关闭流程三症状四根因治理（close_guard）。
- 监听开启后基于会话窗口给出开场建议；情绪追踪器基建预热（开场情绪基线）。

## 分析体验与审查修复（补充）

- 分析进度真实化：按语义相似度估算而非消息计数；分析进行中切换页面不再丢失进度；停止分析失效的三处路径修复。
- 修复好感度分析进程内首次调用必崩的问题。
- RAG 索引状态展示修正（无真实价值提示重建）；RAG 队列自旋崩溃修复（queue_mode 撤锁）。
- 密钥获取 UI 接线与密钥组件统一；全库代码审查（49 项发现）后的 P1-P5 修复与低危批次修复。
- 界面预览图换为真实截图。

## 升级说明

- 直接覆盖安装，数据保留。
- 首次启动后建议：确认设置中的「AI 抽取记忆事实」开关已开启；在联系人记忆管理中点击"回补记忆抽取"，为历史对话批量提炼记忆（后台进行，消耗 Token）。
- 记忆提取全部本地处理；使用远程大模型时内容默认脱敏。
- Linux 版以 tar.gz 形式发布，使用说明见 README。
