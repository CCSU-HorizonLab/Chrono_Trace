# Chrono Trace Beta 1.4 发布说明

**版本**:v1.4.0-beta.1 ｜ **日期**:2026-10-07 ｜ **上一版本**:v1.3.0-beta.1(2026-09-30)

本版共 62 项提交,四条主线:**好感度六维评分体系**、**分析链路大幅提速**、**群聊导入与聊天记录导出**、**打包瘦身**;另有巨型模块拆分与多轮审查修复。

## 好感度:四维 → 六维点数制

- **权重归一引擎上线**:六维点数制(默认 0.40/0.35/0.25/0.12/0.10/0.08),按「在场维度」归一化,缺席维度自动剔除;用户配置的权重此前从未真正生效,本版起关系弹窗内可调各维权重。
- **新增「亲密度信号」维度**:称谓演变(正式称谓→昵称的文本轨迹)、时段与投入(深夜/周末占比与主动发起)、回复对称性(字数投入与表情均衡)三子项,纯规则零模型依赖。
- **新增「LLM 关系评估」维度**:极性分层采样代表性交互对 → 脱敏(红线:脱敏器不可用=整维缺席,绝不发原文)→ 大模型评估;本地 loopback 模型免脱敏;超时/解析失败按缺席处理,不阻断分析。
- **历史分数落库与趋势徽章**:跨口径(维度数/权重变化)不可比时自动保护,不展示误导性趋势。
- 口径修复:态度维度分子分母改为**仅统计对方消息**(此前用户自己的发言被计入对方态度)。

## 分析链路提速(冷跑大幅、暖跑近秒级)

- **嵌入模型换 bge-small-zh-v1.5**(102M→24M 参数):实测 6.3× 提速、fp16 无损;变体机制带回退链,L2 缓存与 RAG 索引按模型名自动隔离。
- **好感度短路**:无新消息且配置指纹未变时直接返回缓存(亚秒级),不再白跑全链路。
- **六维并行计算**:LLM 维网络等待与五个本地维度重叠,维度阶段耗时→max(单维);Stage2 复用 Stage1 切分结果,消同一批消息两阶段各切一遍。
- 预处理杂项:情感阶段不再逐条嵌入(消双倍计算与 pickle 胀库)、jieba 单次分词共享、相似度矩阵乘向量化、sessions/pairs 批量落库、交互对情感 JOIN 预载消 N+1、巨型 IN 分块防崩、暖跑热路径(文本 strip 口径统一消双倍编码、frombuffer 解包)。
- **修复 P0**:会话切分非采样分支 numpy 未定义致向量化**静默回退**逐对计算(附回归测试);关键词 CRUD 后共享词库实例即时刷新(附正反用例);六维并行取消改 0.5s 轮询即停,不再等满全部维度。

## 群聊导入与聊天记录导出

- 群聊数据导入(L1):过滤参数化放行 @chatroom、conversation_type 标记、群消息 wxid 前缀剥离(含存量迁移与 BLOB content 兼容)、联系人列表群徽标。
- **聊天记录导出(L2)**:TXT(纯文本/打印)/CSV(Excel 分析)/HTML(聊天气泡)三格式,可选日期范围,群聊导出含成员昵称区分,一键打开所在文件夹。
- 消息判重键追加 timestamp:V4 分片库 local_id 仅分片内自增,跨分片同号消息此前被误判重复而丢失(唯一索引与启动迁移同步升级)。
- 导入页三键布局补「全量重扫」入口,补齐水位窗口外历史消息的导入途径。

## 导入体验与修复

- 微信导入改**异步任务轮询**:阶段徽章+会话计数+累计条数+耗时与预计剩余;失败不再闪「完成 100%」。
- 画像生成弹窗保持打开直至完成、失败内联提示、判失败键名纠正(此前 LLM 失败被静默吞掉)。
- 关系评估:max_tokens 提至 3072 防思考段截断;采样兼容 list-repr 型 message_ids(此前样本不足致整维缺席)。

## 巨型模块拆分(可维护性)

- `bridge.py` 5335→2457 行,按 API 域拆 9 个 mixin(`webview/api/` 包);
- `monitor_service.py` 4006→1750 行,拆出 UIA 恢复/checkpoint 匹配/回溯落库/建议管线 4 块;
- `llm_engine.py` 3042→1701 行,拆出 API 客户端层与响应解析;
- 8 份编码安全打印拷贝收敛为 `safe_print.py` 单实现;死方法/死导入/死测试批次清理。

## 打包瘦身(Linux 510M)

- 嵌入模型 text2vec→bge:模型段 195M→46M(**-149M**);
- Qt 模块裁剪(Quick3D/PositioningQuick/EglFS 等,ldd 核实 WebEngine 不依赖):-18M;
- 排除 GTK 栈(gi/pycairo,pywebview 可选后端依赖,本项目定死 Qt 后端):-58M;
- torch 预装移除;打包依赖改清华镜像(弱网下 87KB/s→镜像直连)。
- 便携包 568M→**510M**,onedir 952M。

## 数据目录与命名统一

- 用户数据目录统一为无空格 `ChronoTrace`(与打包产物名一致);旧版带空格目录首次启动**自动整目录迁移**(db/日志/模型/GPU runtime 一起搬),迁移失败降级沿用旧目录保数据;显示名(窗口标题/开始菜单)不变。

## 升级须知

- **打包版**:开箱即用;首次启动自动迁移旧数据目录,无需手动操作。
- **开发环境**:`pip install -r requirements-linux.txt`(如曾手动装过 PyGObject/pycairo 请卸载,打包时会拖入 GTK 死重);嵌入模型切 bge 后首次分析会用新模型重算向量(L2 缓存按模型名隔离,旧缓存不冲突)。
- 好感度结果因维度从四维扩到六维,总分口径变化属预期(跨口径趋势已做不可比保护,不会展示误导性涨跌)。
