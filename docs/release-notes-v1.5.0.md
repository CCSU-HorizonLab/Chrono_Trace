# Chrono Trace v1.5.0 发布说明

**版本**:v1.5.0(正式版) ｜ **日期**:2026-10-16 ｜ **上一版本**:v1.4.0(2026-10-10)

本版共 41 项提交,五条主线:**好感度体系重组(六维并四维+独立风险预警)**、**问问微信(历史问答+引用溯源)**、**群聊统计与日报**、**关系体检报告导出**、**RAG 构建提速约 25 倍**;另有画像体验批次与 Linux 稳定性修复。

> **口径变更提示**:好感度从六维重组为「四维 + LLM 维」,总分与旧版不可比(口径护栏自动生效,不会展示误导性跨口径趋势),属预期行为。

## 好感度体系重组:六维并四维 + 风险预警

- **四维 + LLM 点数制**:互动投入 0.40 / 情感共鸣 0.35 / 亲近信号 0.15 / 喜好兼容 0.10 / LLM 关系评估 0.08;「态度倾向」维度解体——效价并入情感共鸣,称呼/隐私/节假日等归入亲近信号;缓存版本 13、口径版本 5,旧结果自动按不可比处理。
- **新增会话统计特征模块**(纯规则零模型):连发未回、长时未回应、主动破冰(>24h 沉默后谁先开口)、早晚安发起、「我们/咱们」共同体表达、敷衍回复率(复用敷衍词表)、撤回频次、日消息量波动,单次扫描一遍产出。
- **风险预警独立模块**(不计入总分,高分掩盖预警是最需要暴露的情形):忽冷忽热 / 单向投入 / 现实否认 / 先热后冷四类信号,**双证据判定**——统计条件与 LLM 对话证据同时满足才「预警」,单边最多「留意」,LLM 维缺席时全部封顶留意;编造引文与原文比对校验,不符即丢弃降级。
- **LLM 评估分层采样与推导纪律**:起源窗 / 高冲突窗 / 近期窗 / 破冰窗四窗采样替代旧极性九桶,prompt 注入统计概要约束 sub_scores 与统计一致;采样裁剪统一丢最旧(修复降序窗 pop(0) 误丢最新样本)。
- 前端五维雷达/卡片/权重表单/风险信号卡全量对齐;总体好感度结论带扩容并入关系维度雷达图,定性分析区不再空置。

## 问问微信:历史自然语言问答 + 引用溯源

- 对当前联系人用自然语言提问(如「她有什么忌口?」),关键词检索 + 向量余弦混合召回,回答附**引用消息气泡**(原文/时间/发送方,点击编号溯源)。
- 提速与可取消:向量**联系人级缓存 + numpy 点积**(首查后近似即时),60 秒短超时单重试,在途请求可取消;缓存指纹校验,取数失败不入缓存(防毒化)。
- 远程模型先过脱敏(问题与上下文均脱敏,失败即阻断);LIKE 通配符转义;无匹配提示不再误导指向全面分析。
- **接入 RAG 长期记忆槽**:问答 prompt 注入联系人事实记忆并保持引用编号语义。

## 群聊统计与日报

- 成员发言统计:发言数/字数/占比、我的排名、活跃时段、高频词,纯本地零模型。
- LLM 日报:按日/近 7 天分段总结,60 秒短超时可取消、单日超预算自动日内裁剪、脱敏补账号键;无模型时优雅降级为仅统计。

## 关系体检报告 HTML 导出

- 单文件 HTML(内联 CSS + Python 计算 SVG 雷达,无 JS 依赖):好感度结果 + 历史趋势 + 风险预警 + RAG 画像摘要 + 基础统计;页脚注明含聊天原文摘录(隐私提示)。

## RAG 记忆链路:自动起点 + 构建提速约 25 倍

- **好感度分析完成自动排队构建索引**:纯历史分析用户不再无索引起点。
- **构建提速实测**:大型群聊(10444 条消息、1587 段、4044 文档+向量)全量重建 **61 分钟以上 → 2 分 14 秒**;普通单聊秒级。三处叠加:嵌入路径跳过无用的情感分类推理、语义抽取候选句按 128 段合批推理(1587 次小批量 ONNX 调用 → 13 次)、无 LLM 抽取时间隔提交。
- **构建可见性**:设置页新增「已就绪 N」(绿)/「构建中 M」(琥珀呼吸点)徽标,构建期间 30 秒自动轮询;构建中只认真实活动,不把历史脏状态冒充排队。
- **启动孤儿回收**:进程重启后遗留的「构建中」状态自动复位重新排队,不再永久卡死状态页(启动即拉起队列 worker)。

## 画像与洞察体验

- **记忆相框点击回顾**:画像回廊的里程碑相框可点击,按时间锚点拉取当时的原始消息气泡回放(会话窗口/日窗口两种锚定,纯图片语音片段有占位提示)。
- 画像弹窗生成中可关闭终止(取消标记贯穿桥接层与 HTTP 尝试边界)。
- 关系洞察页重排:第二部分左四维卡并列右风险预警,维度拆解移页尾通栏,tab 纵向滚动。
- **跨页联系人选择修复**:洞察/实时助手互切不再互相覆盖选中联系人——共享槽仅在用户显式选择时写入;补挂洞察页口径变更提示。

## LLM 调用治理

- 交互调用(建议/问答)通用快速模式:思考模型附 `reasoning_effort=low`,`/no_think` 收敛旧 Qwen3;深度调用(RAG 事实抽取/关系评估)定档 `medium`;模型级 `extra_body` 显式配置优先透传。

## Linux 稳定性

- **强制 pywebview Qt 后端**:WebKitGTK 下 localStorage 为 null 导致切页白屏,根治;Qt 启动失败回退自动探测。
- safeStorage 统一 storage 降级(补实时监听裸访问位点);入口生命周期收敛 `run_main_window`。

## 其他修复

- 互动投入长文阈值接线(配置真实生效于回应对称性);engagement 消息加载重复解码收敛为单次;特征提取空库早返回补 `skipped` 键;画像好感度读取限定当前口径(新旧口径行不再混标);`is_warm` 公共 API 调用不存在方法的潜伏崩溃修复(附回归测试);模型导出脚本量化分支变量名 NameError。

## 升级须知

- **打包版**:开箱即用。好感度总分因维度重组口径变化属预期,首次进入会自动要求重新分析(旧缓存按口径版本失效);RAG 已就绪联系人不受影响,无需重建。
- **开发环境**:`pip install -r requirements-linux.txt`;全量后端测试 1045 用例通过。
- Linux 若仍遇到输入法候选框不跟随,为 Qt 私有 API 版本死结的已知限制(方案已评估,后续独立排期)。
