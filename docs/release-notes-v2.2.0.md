# Chrono Trace v2.2.0 发布说明

**版本**:v2.2.0(功能版) ｜ **日期**:2026-10-21 ｜ **上一版本**:v2.1.0(2026-10-20)

一条主线:**界面全面重做为「墨痕暖白」视觉语言**,外加**无边框窗口自绘标题栏**。本次为纯前端/窗口层重做,不涉及数据、导入、监听与分析链路的行为变化。

## 界面重做:墨痕暖白(全局)

传统 PC 后台式语法整体退场(渐变紫顶栏、纯白平铺、彩色投影、hover 上浮、生硬 1px 灰边框),统一为对话日志式的暖纸手帐气质:

- **色彩令牌唯一来源**:暖纸画布 `#FAF9F7` + 白卡面 + 沉底色阶分层(卡片不再靠描边),主色墨紫 `#5A4BC4`,语义色青绿/琥珀/珊瑚各配淡底;全站零渐变、零彩色投影。
- **字体修正**:正文此前实际是系统默认(Google Fonts 离线永不加载)——现明确系统中文栈 + `tabular-nums` 对齐数字;得意黑只用于品牌字与大数据数字。
- **五套并行紫色收敛为一套**;126 种圆角值收敛为 6/10/14/999 四档;暖调阴影三档。
- **样式架构纪律落地**:全局 `button` 元素选择器皮肤退场;`base.css` 拆解删除;全库 `!important` 从 165+ 清到合法存量 3 处;21 个幽灵变量清零,并有冒烟测试守门(未定义令牌/旧名回潮/元素选择器回潮/海报区引变量四类违规直接红)。

## 无边框窗口自绘标题栏(双平台)

系统原生灰色标题栏与暖白内容区的「两层皮」割裂消除:

- 顶栏即标题栏:空白处拖动移动窗口、双击最大化/还原,右侧自绘 最小化/最大化/关闭 三键。
- 四边 6px + 四角 12px 缩放热区,最大化时自动隐藏;关闭键沿用原确认链路(询问/最小化/退出,按设置分派)。
- 最大化状态由后端查实际窗口状态取反,Win+Up、窗口管理器快捷键等系统级最大化后再点按钮不会状态错位。
- Linux(Qt)走 `startSystemMove/startSystemResize`(X11/Wayland 通用,WM 接管拖拽);Windows 走 `WM_NCLBUTTONDOWN` 原生标题栏语义(与悬浮窗同链路)——窗口句柄枚举与最大化查询已改 `win32process`/`ctypes` 正确接口(此前误用 pywin32 未导出属性,异常被吞会静默失效),双平台均经真机验证。
- 默认窗 1200×720、最小 880×640;全局弹窗与画像生成弹窗限高 86vh+内部滚动,小窗口下不再超出视口。

## 图表统一浅色(单一来源)

- 新建 `chartTheme.ts`:数据色板(墨紫+珊瑚+青绿+琥珀+石板)、墨紫热力色带、`chrono` 主题与白卡 tooltip,全部 ECharts 一律接它,不再散写轴色。
- 悬浮窗六图从深色驾驶舱统一为浅色(修掉白卡上深色轴字的既有错配);大五色板单源化。
- 好感度分数、里程碑、活动日历等大数据数字换得意黑展示,表格数字保持正文栈。

## 逐页换装清单

Home 向导卡群、Analytics 七页签(关系洞察/互动特征/内容时间线/智能问答/时光深度/TA 画像/实时助手)、时光深度与画像群、Settings、记忆管理(联系人事实/事实详情弹窗)、悬浮窗全部换装;卡片统一去整框,按钮/输入/徽章等功能边保留。

## 安全修复

- 悬浮窗情绪曲线 tooltip 此前把聊天原文未经转义拼进 HTML 渲染,被监听人发一条含恶意标签的消息即可在主窗口执行脚本——已加 HTML 转义。

## 升级须知

- 窗口操作方式变化:标题栏现为页面顶栏(拖空白处移动/双击最大化),系统标题栏不再存在。
- 视觉行为整体变化,无数据迁移;分享海报模板区豁免未动,导出效果与 2.1.0 一致。
- `docs/frontend-visual-system.md` 为新视觉规范速查,后续改样式先读它。
