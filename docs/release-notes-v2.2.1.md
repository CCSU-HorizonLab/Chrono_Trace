# Chrono Trace v2.2.1 发布说明

**版本**:v2.2.1(增强版) ｜ **日期**:2026-10-25 ｜ **上一版本**:v2.2.0(2026-10-21)

一条主线:**时光深度新增「关系章节」叙事层**(变点分段 → 章节卡 → 摘要金字塔 → 全局弧线),同时**智能问答接入联系人长期记忆**并诚实说「不记得」,RAG 检索做了一轮集中的性能与正确性加固;另修无框窗口 Windows 侧的缩放/拖动稳定性与主动性分析口吻。

## 关系章节:时光深度新面板

长关系动辄几百周,传统等分时间段把「故事」切没了。关系章节按**统计变点自动分段**——用消息密度、TA 占比、正向率、回复时延四个信号找关系结构的真实转折点:

- **周量柱 + 章节分界线**:每周消息量与章节边界一图并陈,分界处即变化点;
- **周级大五分布带**:五维五行,每章一段,人格气质的漂移随章节肉眼可读;
- **章节卡**:每章的统计摘要与变化点说明;
- **摘要金字塔**:面板头部「全量摘要」入口,月摘要 → 章节归并(LLM 增量缓存,已算月份不重跑),产物同时注入画像与章节卡;
- **过渡卡与全局弧线**:章节间的过渡叙述 + 顶部的全局叙事弧,整段关系像一篇有起承转合的长文。

**分段语义统一**:词云演变、大五人格演变等面板从固定时间分段改为按关系章节边界切段——同一个「章」,贯穿所有演变视图。细节修复:章节图 x 轴标签随跨度自适应、tooltip 补全周日期、章节段首尾时间戳跳过沉默空周。

## 智能问答(微信问问)接入长期记忆

- **记忆槽过门控**:此前问「她生日是什么时候」会注入低相关度的无关事实——现在检索结果须过相关性门控,低于事实线的不进上下文;问答侧事实线比实时链路更严(0.42,实时链路 0.30 兼有低分兜底语义);
- **诚实说「不记得」**:记忆库确无相关记录时,明确提示「记忆库中没有与此问题直接相关的可靠记录」,阻断模型从无关聊天里硬凑答案——宁可承认不记得,也不编;
- **事实向量口径统一**:回填路径与主路径嵌入同一文本,重复事实不再两套向量。

## RAG 检索性能与正确性

- **并发与矩阵化**:事实融合并发化、批量嵌入与检索矩阵化、LLM 连接复用;
- **关键词召回**:平滑 IDF 加权(低频词不再爆炸),文档 token 统计预计算;
- **索引与判重**:分片预映射、判重补算水位化、RAG 组件线程级复用;
- **正确性修复**:检索超时清空与维度截断等;导入改事务化批写;词云结果持久缓存(重复打开秒出)。

## 无框窗口(Windows)稳定性

- 边缘缩放改**前端驱动逐帧 SetWindowPos**(弃用 NC 消息循环,卡顿与失焦丢失修复),标题栏拖动同改逐帧 move_to;
- 补 THICKFRAME 样式与屏幕坐标锚点,缩放热区不再错位;
- 默认窗口尺寸调整为 1200×720。

## 主动性分析口吻修正

49% / 51% 这类近对半的发起占比,此前会被定性为「您更主动/对方更主动」——现在改**双闸门**:差异须同时通过双侧二项检验(p<0.05,小样本噪声被挡)与效应量门槛(Cohen's h≥0.2 才谈方向,≥0.5 才说「明显」),近对半一律「基本对半,谈不上谁更主动」,显著差异分「略偏向/明显在一侧」两档表述;不足 5 场会话不下结论。实时建议链路的关系状态判定同口径。

## 工程与仓库卫生

- 文档、测试与示例截图清除人名、wxid 与真实聊天内容等可识别信息;
- 删除 archive 归档、失效评测脚本与死链;docs 导航重写。

## 升级须知

- **分段语义变化**:词云/大五演变的分段从固定时间窗改为关系章节边界,视图外观与 2.2.0 不同,属预期行为;
- **问答记忆门槛提高**:此前会被注入的低相关记忆,现在改为「无相关记录」提示,属预期收紧;
- **存量事实向量不主动重算**:已有事实的旧口径向量继续可用(检索质量略降),下次在记忆管理里重建索引时自然统一到新口径;
- 无数据迁移要求,已有库与导入数据照常使用。
