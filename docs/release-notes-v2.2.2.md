# Chrono Trace v2.2.2 发布说明

**版本**:v2.2.2(增强版) ｜ **日期**:2026-10-29 ｜ **上一版本**:v2.2.1(2026-10-25)

一条主线:**分享海报全面扩展**(作息热力格 / 年历 / 细节分镜 / 方形称号卡),**AI 关系评估支持瞬时缺席后仅补评**,外加**两轮全系统审查产出的 25 项稳定性加固**——脱敏红线补齐最后漏网、监听与分析的竞态族修复、前端切联系人竞态收口。

## 分享海报:新分镜与称号卡

- **作息热力格**:双方活跃时段的错峰/共振一眼可读(定向版字段错用致长图空白的问题已修);
- **年历分镜**:全年消息密度日历,关系的浓淡季节自现;
- **细节分镜**:新增统计细节格,海报信息密度提升;
- **称号分级**:称号按稀有度分级话术,并支持**方形称号卡**独立导出(加料迷你数字行高频词修复);
- **默契格改 bento 主格版式**:主格区分于细节格,层级更清;
- 公开版/自我版落款加**仓库二维码**(静态资产内联,离线可用);
- 海报导出后**自动复制到剪贴板**;
- 语气曲线按幕卡精确内宽 566 布局,不再溢出。

## AI 关系评估:瞬时缺席仅补评

全面分析已完成、仅 AI 关系评估瞬时缺席(网络抖动 / 模型限流等)时,**不再需要重跑整场分析**——直接对既有本地四维补评 LLM 维并重新归一:

- 补评前缓存中的本地维权重先按当前声明值复位,与全量分析装配口径对齐,杜绝双次归一(分母 1.0+LLM 而非声明和)导致的失真;
- LLM 无效分值判缺席、响应 null 字段容错,异常不再污染已有评分。

## 稳定性:两轮全系统审查(10 个视角 + 随机复核)修复

### 脱敏红线(最重要)

- **先截断后脱敏**:事实抽取的 400 字截断此前在脱敏之前执行——跨边界被切断的 PII 残段(手机号只剩 7 位)不匹配完整模式、原样出网。改为先全量脱敏再截断;
- **中文贴字失效**:脱敏正则的 `\b` 词边界对中文永不成立(「我身份证110…」紧贴中文时边界不成立)。改为显式字符类环视,身份证/银行卡/邮箱/链接在中文语境全部恢复命中;补充库落私有目录;
- **画像双 profiler 漏网**:联系人画像/自我画像的 prompt 携带聊天原文直发远程 LLM——全仓 10 个 LLM 消费方中的最后两个漏网点。现已出网前整段脱敏、失败即阻断,绝不降级发原文。

### 监听链路竞态

- 启动互斥在锁内置位,双击开始监听不再产生两会话并存;
- 收尾迁移读批次与标记处理统一用冻结账号,停止监听后切换账号不再丢批次;
- 快照临时文件名带 pid+线程 id,跨实例并发刷新同一分片不再互踩;
- 主库页1解密失败但 WAL 帧已修复的快照不再被误判抛弃;
- 15 秒延迟收尾分支不再误杀等待窗内新开的监听会话;
- 建议抑制时间戳提前到 LLM 调用前,推理窗口内不再连发两张重复冷场卡片。

### 分析口径

- 按会话字数统计补上每段末条消息(此前 N 段系统性丢 N-1 条);
- 海报词云从「只取窗口尾部 2000 条」改为**全窗等距抽样**,长时段回溯不再系统性偏近期;
- 好感度跨实例守卫:重试不再覆写运行中实例,进度查询与互斥不再被架空;
- 特征提取失败落终态,占位任务不再永久卡死该会话的分析请求;
- 微信分片无 Name2Id 表判良性跳过,增量导入水位不再永久冻结导致全窗重扫;
- torch 时代残留源权重不再误报「分析可用」——可用性由 ONNX 产物单点判定。

### 前端竞态

- 切换联系人时丢弃过期异步结果:分析进度轮询末次写回、特征统计、活跃日历等全族补齐纪元守卫——A 联系人的结果不再覆盖 B 的页面;
- 单次轮询异常不再被当作提取成功完成(半成品特征当完整结果的根源);
- 词云演变切换视角后图表实例不再绑定孤儿容器(流动图永久空白);
- 建议台词 speeches 脏 JSON 容错,单条脏数据不再中断整个会话继承。

### 工程卫生

- Qt 后端剪贴板权限请求致进程 abort 的前端跳过(Linux);
- 时光深度默认窗与全部快捷键改用会话首条消息日期(原 2000 年占位);
- 删除死代码:旧版数据库解析器(235 行,V4 适配层早已取代)、关系上下文参数调整(从未被消费);
- 密钥捕获的登录态探测/重启微信分派收敛进 keys 工厂,业务层不再散写平台分支;
- 实时情感路径的每 3 秒重复建表/查列清理,schema.sql 保持唯一建表源。

## 升级须知

- **海报外观变化**:新增分镜与称号卡属预期增强;词云分镜从尾部抽样改全窗等距抽样,长时段海报的词分布与旧版不同,属口径修正;
- **远程 LLM 配置方**:画像生成现在也走脱敏(与问答/建议/事实抽取同规),prompt 中出现的手机号/身份证/地址等将被占位符替换,属隐私增强的预期行为;
- 无数据库结构变更,老库无需任何操作。
