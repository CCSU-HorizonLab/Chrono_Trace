# Chrono Trace v3.0.1 发布说明

**版本**:v3.0.1(重构版) ｜ **日期**:2026-11-09 ｜ **上一版本**:v2.3.1(2026-11-08)

一条主线:**信息架构重设计**——主导航从七页收敛为「脉搏 / 时光 / 画像 / 智囊」四页,分析入口并入脉搏专业视图、群聊工作台迁入时光页,数据导入与设置收进右侧齿轮抽屉,空库首启四步引导直落脉搏。在此骨架上长出四块新能力:**画像页镜像双栏**(TA 的画像与我的画像同屏对照)、**AI 分身**(以 TA 的画像、语气采样与长期记忆模拟对话)、**年度报告与纪念册产线**(任意时间窗聚合,公开/定向双模板)、**表情博物馆**(双方 Top 榜/小时节奏/自定义表情墙)。外加**回复陪练**、**关系周报**与一轮交互与数据完整性修复(文字选择、情感补算自愈、LLM 取消语义)。共 31 个提交。

## 信息架构重设计:七页收敛四页

- **脉搏成新首页**:判读横幅(一句话先给答案)+ 三联指标卡(温度/主动天平/回应中位)+ 月度速览 + 专业视图折叠层——原分析工作台并入为专业视图(关系洞察/互动特征两页签);指标口径单一来源 `pulse_metrics`,周报模板版先落库、AI 后台 UPSERT 覆盖;
- **时光页时间轴叙事**:单聊年份轴 + 章节色块 + 五锚点导航(关系章节/情绪/词云演变/表情博物馆/大五人格/画像分段演变/里程碑),深钻区默认折叠;页头「导出」收口聊天记录导出(TXT/CSV/HTML);群聊选中切群聊工作台(发言统计 + LLM 群日报);
- **智囊页对话统一**:问答/陪练/实时三模式分段器,页头选人贯通全站;群聊下陪练/实时置灰回退问答;
- **数据与设置收进右侧抽屉**:齿轮入口 + 四组页签(数据与账号内嵌导入 / 模型与计算 / 联系人记忆 / 通用),导航撤数据位;
- **空库首启四步引导**:标记重要的人→确认数据目录→导入→直落脉搏,导入管线抽为共用组件;
- **选人状态跨页贯通**:共享联系人作用域,切页不再丢人。

## 画像页 v2:镜像双栏

- 左「TA 的镜像」:画像档案 + 大五印象卡(「查看演变」链去时光页)+ 专属梗词典(全会话跨度、分侧双色比例条);右「我的镜像」:我的画像 + 镜像对照(回复中位/开场次数/字数投入同量纲双轨 + 对照句 + 短板提示,纯 SQL 直出不依赖跑过分析);
- 底部海报工坊,海报模板注册表公开/自我版经投影消费,类型上拿不到敏感字段。

## AI 分身:以 TA 的口吻模拟对话

- 人格提示词三路素材:画像档案(schema 代际匹配才用,缺席降级)+ 语气采样(近 2000 条 TA 文本纯本地统计:中位句长/短句占比/高频词/常用表情/等距原话样本,样本不足直接拒答)+ RAG 记忆槽;temperature 0.7 口吻优先;
- 流式打字机(与问答同推送通道),常驻「AI 模拟非本人」边界横幅,逐条气泡带边界标注(截图分享后仍可辨认);模拟止于应用内对话不提供代发。

## 年度报告与纪念册

- 时光页年份轴拖选任意区间→纪念册;一键年度报告取跨度内最晚自然年交集;报告工坊模板组双档(公开版投影脱敏/定向版全量);
- 数据服务:窗口表情 Top、专属梗两段式挖掘(等距抽样圈候选 + 全窗精确计数,转发卡片整条剔除)、早安晚安节奏、好感温度封皮(无分析优雅降级)、里程碑按章节分组;长图七幕缺数据整幕跳过、页码动态重排。

## 表情博物馆

- 双方 Top 榜、小时节奏热力、自定义表情墙;统计聚合宽容提取(Unicode 簇/内置占位/自定义 md5),快照缓存不重算。

## 回复陪练

- 贴 TA 消息出三温度档回复方向(稳一稳/进一步/缓一缓)+ 可能走向预判;与问答共用检索、脱敏红线与 LLM 调用骨架。

## 修复与加固

- **文字选择全线恢复**:QtWebEngine 定制 UA 样式表对 body 施加 important 级全站禁选(仅真窗口可复现,E2E 的 Chrome 无此规则),作者样式同级 important 对抗恢复原生选择;分析文字撤复制按钮,统一「拖选 + Ctrl+C」,点击别处取消高亮;
- **情感补算链自愈**:补算 UI 入口(10 月页面重组时意外丢失)迁回时光页情绪面板;换代 purge 补结构校验——tag 匹配而缓存表缺列的库自动重置重建,修复 v2 换代当日中间态库情感写入静默失败;
- **交互式 LLM 取消语义**:取消标记不再跨轮传递,前端卸载时的无条件取消不再毒化下一轮;群日报与画像生成补取消注册与串行门闩;
- 口径统一与杂项:主动性双闸门复用、深夜 0-4 点边界、周报不取思维链、悬浮窗跳智囊、年报公开版剥日期与梗实体过滤、分身语气档案并入脱敏红线(功能词过滤)。

## 测试与工程

- **前端 E2E 测试套件**:Chrome 驱动全页面用户旅程(导航/选人/页签/打字机/降级态),61→66 断言含文字选择行为守护,零 pageerror 门禁;README 截图产线(E2E 虚构数据)全量重拍对齐四页导航。

## 升级须知

- 导航结构变化较大:原分析页解散(单聊工作台在脉搏专业视图、群聊工作台在时光页),数据导入在右上角齿轮抽屉;
- 旧库无兼容迁移(项目约定):缺列报错时删除 `chrono_trace.db` 重导即可;情感缓存缺列的中间态库(v2.3.1 当日升级过)启动即自动重置,重跑补算或全面分析恢复;
- 模型与数据口径无换代:情感引擎仍为 v2(v2-ctx-20261107),无需重蒸馏。
